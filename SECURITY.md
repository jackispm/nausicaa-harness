# Security Policy

Nausicaa is beta software. Do not use it as a security boundary for hostile
code unless it is run inside an independently managed sandbox or virtual
machine.

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub Security Advisories when
that feature is enabled for the repository. If it is unavailable, contact the
maintainers privately before opening a public issue. Include reproduction steps,
the affected version or commit, and the smallest useful proof of impact.

Do not include API keys, credentials, private repository contents, or other
secrets in an issue, pull request, log, or test fixture.

## Supported versions

Only the latest beta release on the default branch is actively maintained until
the project publishes a longer-term support policy.
